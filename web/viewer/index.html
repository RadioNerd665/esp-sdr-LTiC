Connection and safety

Connect the LilyGO T-Internet-COM running compatible Ethernet snapshot firmware to a trusted LAN and open http://DEVICE_IP/ directly. The firmware must embed and serve the four viewer files at the root and provide its snapshot API at the same origin.

The viewer sends X-ESP-SDR: 1. The device API requires that header, rejects mismatched Origin and does not allow cross-origin requests. Do not expose the device to untrusted networks; it provides neither authentication nor encryption. HTTPS pages cannot fetch an HTTP device because of mixed-content restrictions.

Requests tune the receiver and use its exclusive capture lease. Other UART or TCP clients may make it busy. Stop snapshots before using other clients. These are intermittent snapshots, not streaming I/Q or a calibrated instrument.
