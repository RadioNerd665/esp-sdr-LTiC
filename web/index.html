LilyGO T-Internet-COM installer

Experimental: install the esp32lilygo firmware on an ESP32 T-Internet-COM over USB serial. Hardware validation is still required.

Use Chrome or Edge with Web Serial on localhost or HTTPS. Connect the board with a data-capable USB cable and close other serial applications.

Flashing erases the sectors occupied by the images, including any data stored there. Use only on the intended board. Do not disconnect during writing. Secure Boot and flash-encrypted devices are not supported.
